Integration guide

Prodbench for Zendesk Support

Install and configure the Prodbench Zendesk integration to connect Zendesk tickets with Prodbench work items, right from the ticket sidebar.

Audience: Zendesk administrators and Prodbench users Integration: Prodbench for Zendesk Support

1.Overview

The Prodbench Zendesk Integration enables support teams to connect Zendesk tickets with Prodbench work items, helping teams track customer requirements, identify existing development initiatives, and escalate customer feedback directly from Zendesk.

Once installed and configured, the integration allows users to:

  • View suggested work items relevant to the current Zendesk ticket.
  • Search for existing work items in Prodbench.
  • Link Zendesk tickets to existing Prodbench work items.
  • Create new work items directly from the Zendesk ticket interface.
  • Associate tickets with the appropriate Prodbench workspace through workspace mapping.

This guide explains how to install, configure, and start using the integration.

2.Prerequisites

Before installing the integration, ensure the following requirements are met:

  • An active Prodbench account.
  • Administrator access to Prodbench to enable the integration and generate an API token.
  • Administrator access to your Zendesk Support account.
  • The latest Prodbench Zendesk application package (ProdbenchApp.zip). You can download it below.
  • Your Prodbench account subdomain.
Important: Administrator privileges are required for the initial installation and configuration. Once setup is complete, regular users can access the integration within Zendesk tickets.

3.Enable the Zendesk Integration in Prodbench

The first step is to enable the integration in your Prodbench account and retrieve the API token required for authentication.

Step 1: Sign in to Prodbench

Log in to your Prodbench account using an administrator account.

Step 2: Enable the Zendesk Integration

Navigate to the integrations section in Prodbench and enable the Zendesk Integration.

Step 3: Copy the API Token

Once enabled, Prodbench displays an API token that will be used to authenticate the Zendesk application.

  1. Locate the API token displayed after enabling the integration.
  2. Copy the token.
  3. Store it securely until you complete the Zendesk app installation.

You will enter this token in the API Token field during the Zendesk installation (see Section 5).

Security note: Treat the API token as a confidential credential. Do not share it publicly or expose it in screenshots or documentation.

4.Install the Prodbench App in Zendesk

The Prodbench integration is currently installed as a private Zendesk application.

Step 1: Download the Application

Download the latest Prodbench Zendesk application package:

ProdbenchApp.zip
Prodbench app package for Zendesk Support
Download

Keep the package compressed. It must be uploaded as a ZIP file.

Step 2: Open the Zendesk Admin Center

  1. Sign in to your Zendesk Support account as an administrator.
  2. Open Zendesk Admin Center.
  3. Navigate to Apps and integrations → Apps → Zendesk Support apps.
  4. Select the option to upload a private app.
Note: Private app installation is required until the Prodbench application becomes available through the Zendesk Marketplace.

Step 3: Upload the Application

  1. Click Upload private app.
  2. Select the ProdbenchApp.zip file.
  3. Follow the prompts to upload the application.
  4. Once uploaded, the application configuration screen will appear.

6.Configure Workspace Mapping

Workspace mapping connects Zendesk brands with their corresponding Prodbench workspaces. This ensures that work item suggestions, searches, and newly created work items are associated with the appropriate workspace.

Step 1: Open the Prodbench App

  1. Navigate to the Zendesk Support ticketing interface.
  2. Open any existing ticket.
  3. Locate the Prodbench application in the right-hand sidebar.

Step 2: Access Workspace Mapping Settings

Click the gear icon () in the top-right corner of the Prodbench application to open the workspace mapping settings.

Step 3: Review or Configure Workspace Mapping

Automatic mapping

If your Zendesk account has only one brand and your Prodbench account has only one workspace, the integration automatically maps the Zendesk brand to the available Prodbench workspace. No manual configuration is required in this scenario.

Manual mapping

If your account contains multiple Zendesk brands or multiple Prodbench workspaces, review and configure the mappings as needed.

  1. Open the workspace mapping settings using the gear icon.
  2. Select the appropriate Prodbench workspace for each Zendesk brand.
  3. Save the mappings.
Note: Zendesk accounts include a default brand. If there is only one brand and one Prodbench workspace, the mapping is created automatically. Administrators can review or modify workspace mappings at any time.

How workspace mapping works

The mapped workspace determines where the integration searches for, suggests, and creates work items.

  • Work item suggestions: Displays relevant work items from the mapped Prodbench workspace.
  • Work item search: Searches for existing work items within the associated workspace.
  • Create work item: Uses the mapped workspace when creating new work items from Zendesk.
Important: Verify that each Zendesk brand is mapped to the appropriate Prodbench workspace to ensure customer requirements are tracked correctly.

7.Using Prodbench Within Zendesk

Once the installation and workspace configuration are complete, the integration is ready for everyday use. Regular Zendesk users can open tickets and access Prodbench directly from the ticket sidebar.

View suggested work items

When a Zendesk ticket is opened, the Prodbench application automatically displays suggested work items relevant to the ticket. These suggestions help support agents identify whether a customer-reported requirement, issue, or feature request is already being tracked in Prodbench.

Search existing work items

Users can search for work items in Prodbench to find existing requirements or development tasks.

Link a ticket to a work item

If an appropriate work item already exists, users can link the Zendesk ticket to that item instead of creating a duplicate.

Create a new work item

If no relevant work item exists, users can create a new work item directly from the Zendesk application. The configured workspace mapping helps associate the new work item with the correct Prodbench workspace.

8.Troubleshooting

IssueRecommended action
Prodbench app is not visible in the ticket sidebar.Verify that the application has been installed and enabled in Zendesk Support.
Authentication fails.Verify that the API token matches the token generated in Prodbench and that the account subdomain is correct.
Work item suggestions are not displayed.Check the API configuration and confirm that the appropriate workspace mapping has been saved.
Work items appear under an incorrect workspace.Open the gear icon in the Prodbench app and review the workspace mapping.
Workspace mapping needs to be changed.Click the gear icon in the top-right corner, update the mappings, and save your changes.

If the issue persists after checking the configuration, contact the Prodbench support team at hello@prodbench.com.
